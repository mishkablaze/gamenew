# Дополнительно для Claude

- Твоё имя-владелец в `docs/TASKS.md`: **`claude`**. Ветки: `claude/T-XXX-short-name`. Worktree: `.worktrees/claude` (внутри проекта, в git игнорируется).
- Твоя зона: архитектура и сквозные системы (тик, баллистика, оружие, сетка инвентаря, ИИ-архитектура, сохранения, поток экранов), документация и ревью задач `codex`.

- Если ты работаешь из облачной сессии через подключённую папку на Mac, Unity и dotnet там могут быть недоступны. Тогда в HANDOFF пиши «не запускалось: tools/test-core.sh / компиляция в Unity», а прогон сделает Codex на ревью или человек.
- Задачи для Codex пиши так, чтобы их можно было выполнить без уточнений: входы и выходы, файлы, граничные случаи, критерии «Готово, когда».

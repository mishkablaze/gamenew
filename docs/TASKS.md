## Карточки задач

### M0 — Фундамент

#### T-001 · Установить Unity, создать проект, git + LFS, worktree
**Сделать (человек):**
1. В Unity Hub установить Unity (сделано: **6000.6.7f1**) с модулями: Mac Build Support (IL2CPP) и Windows Build Support (Mono).
2. В Hub создать проект по шаблону **Universal 3D** (URP) с именем `Raidline`, например в `~/Documents/Dev/`. Удалить демо-контент шаблона (`Assets/TutorialInfo`, `Readme`), если он есть.
3. Закрыть Unity. Скопировать в корень проекта содержимое пакета документов: `AGENTS.md`, `CLAUDE.md`, `README.md`, `docs/`, `.gitignore`, `.gitattributes`, `.editorconfig`.
4. В терминале:
   ```bash
   brew install git-lfs            # если ещё нет
   cd ~/Documents/Dev/Raidline
   git init -b main && git lfs install
   git add . && git commit -m "T-001: initial Unity project and docs"
   git worktree add --detach .worktrees/claude main
   git worktree add --detach .worktrees/codex main
   ```
5. Создать **приватный** репозиторий (GitHub или любой другой git-хостинг с поддержкой LFS) и запушить `main`: через него проект синхронизируется с Windows-ПК (T-903).
6. Подключить папку проекта к Claude (кнопка «Add folder» в приложении Claude), чтобы Claude работал прямо в ней.

**Готово, когда:** проект открывается без ошибок; есть первый коммит; существуют оба worktree.

  - Все остальные: `autoReferenced: false`, ссылки строго по таблице §3, без циклов.

Скрипт печатает сводку (passed/failed) и возвращает код выхода Unity.

**Готово, когда:** все настройки применяются без перезапуска (кроме тех, где это невозможно — они помечены).

#### T-902 · Аудит производительности
**Сделать:** прогон Benchmark на MacBook Air и Windows-ПК; поиск и исправление горячих точек; проверка 0 GC; Burst в баллистике; бюджет ИИ. Отчёт «до и после» в HANDOFF.
**Готово, когда:** бюджеты PLAN §3 выполнены на эталонном ноутбуке (после прогрева, от сети) и на MacBook Air; минимальные и рекомендуемые требования для страницы магазина записаны в DECISIONS.

#### T-903 · Windows-ПК: настройка, проверка, замеры (человек)
**Один раз:** установить на ПК Unity Hub и **ту же версию** Unity, что на Mac (6000.6.7f1), с модулем Windows Build Support (IL2CPP); Visual Studio 2022 Build Tools с компонентом «Desktop development with C++» (нужен для IL2CPP); Git for Windows и Git LFS; клонировать репозиторий. Unity на ПК можно активировать той же личной лицензией.
Проверить в Диспетчере устройств, обычная у ноутбука GTX 1660 Ti или «with Max-Q Design», и дописать в PLAN §3. В панели NVIDIA назначить игре и редактору Unity «Высокопроизводительный процессор NVIDIA», чтобы они не запускались на встроенной Vega.
**Каждую веху начиная с M2:** `git pull`, собрать IL2CPP-сборку через `tools/build.sh win release` (в Git Bash), прогнать `-benchmark` на пресетах Low и Medium в 1080p, приложить CSV в HANDOFF. Сверить с бюджетами PLAN §3: GPU ≤ 13 мс на Low, главный поток ≤ 10 мс.
**Правила замера на ноутбуке:** только от сети; профиль производительности в утилите производителя — максимальный; перед замером 10 минут игры для прогрева; прогон бенчмарка не короче 5 минут, чтобы троттлинг попал в цифры; в Perf HUD убедиться, что используется GTX 1660 Ti, а не Vega. Проверить полноэкранный и оконный режимы, разные разрешения, Alt+Tab, переназначение клавиш.

#### T-904 · Скрипты сборки (Mac и Windows-ПК)
**Сделать:** `BuildScript.cs` (batchmode-методы `BuildWindows`, `BuildMac`; dev/release; версия из `git describe`); `tools/build.sh <win|mac> [dev|release]` — сам определяет ОС и путь к Unity (`/Applications/Unity/Hub/Editor/<ver>/…` на Mac, `C:/Program Files/Unity/Hub/Editor/<ver>/Editor/Unity.exe` на Windows; на Windows запускается из Git Bash). На Mac `win` собирает Mono (быстрая проверка), на Windows-ПК — IL2CPP (релиз). Выход — `Builds/<platform>/<version>/`. CI (GitHub Actions + GameCI) не делаем: он в бэклоге (D-015).
**Готово, когда:** на Mac собираются macOS IL2CPP и Windows Mono, на Windows-ПК — Windows IL2CPP, каждая одной командой.

#### T-905 · Steamworks

# Решения (ADR-lite)

Каждое решение записывается с номером, датой, статусом и коротким обоснованием. Статусы: **принято**, **предложено** (ждёт человека), **заменено D-xxx**. Агенты не принимают решений со статусом «принято» без человека: они пишут «предложено» и выносят вопрос в HANDOFF.

---

### D-001 · Движок — Unity 6.6 (6000.6.7f1) + URP 17.6 (Forward+)
2026-10-30 · **принято** (обновлено: вместо 6.3 LTS)
Unity уже знаком по текущему проекту и даёт Windows и macOS из одной кодовой базы (а в M10 — headless Linux-сервер). Человек создал проект на 6000.6.7f1. Это Update-релиз Unity 6: Unity позиционирует такие релизы как готовые к продакшену и рекомендует их для новых проектов, а переход между версиями Unity 6 сделан плавным. На ближайшую LTS-версию переходим, когда она выйдет, отдельной задачей. На Windows-ПК ставим **ровно ту же** версию. Forward+ нужен для GPU Resident Drawer и большого числа источников света.

### D-014 · Платформы — только Windows и macOS; управление — клавиатура и мышь
2026-10-30 · **принято** (заменяет D-003)
Steam Deck и Linux-клиент убраны из целевых платформ по решению человека: минус одна платформа для сборки, тестов и пресета. Вместе с Deck в бэклог уходит поддержка геймпада (жанр традиционно играется с мышью). Ориентиры производительности — минимальная конфигурация Windows и MacBook Air (PLAN §3). Windows-сборка, скорее всего, будет запускаться на Deck через Proton, но мы это не обещаем и не тестируем. Консоли и мобильные устройства по-прежнему вне рамок.

### D-015 · Windows IL2CPP-сборки и замеры — на своём Windows-ПК; CI откладываем
2026-10-30 · **принято**
У человека есть Windows-ПК. IL2CPP под Windows нельзя собрать на Mac, а свой ПК проще и бесплатнее облачной сборки (не нужны лицензии Unity в CI). Проект синхронизируется через приватный git-репозиторий с LFS. Mac собирает macOS (IL2CPP) и Windows (Mono) для быстрых проверок. CI (GitHub Actions + GameCI) — в бэклоге, вернёмся к нему ближе к релизу.

### D-016 · Эталон для замеров = минимальная конфигурация: ноутбук человека (Ryzen 7 3750H, GTX 1660 Ti Mobile, 16 ГБ)
2026-10-30 · **принято**
Все замеры под Windows снимаем на нём по правилам T-903 (от сети, после прогрева). Слабое место — 4-ядерный мобильный процессор, поэтому бюджеты CPU (главный поток ≤ 10 мс, ИИ ≤ 1.5 мс) проверяются здесь. Бюджет GPU — ≤ 13 мс на пресете Low в 1080p. Минимальные требования для магазина выводим из этого ноутбука (PLAN §3).
